## 一、项目概述

### 1.1 项目定位

亲情陪伴系统是一套 **AI 驱动的老年情感陪伴对话系统**，基于专利《一种亲情记忆驱动的适老共情对话方法》实现。系统通过家庭记忆检索、用户画像、实时情绪感知和老年适配回复生成，为独居/空巢老人提供有温度的 AI 语音陪伴。

### 1.2 核心用户群体

```
┌──────────────────────────────────┐
│           亲情陪伴系统             │
├──────────────────────────────────┤
│                                  │
│   ┌─────────┐    ┌──────────┐   │
│   │  家人端  │    │  老人端   │   │
│   │ (子女)  │    │ (父母)   │   │
│   └────┬────┘    └────┬─────┘   │
│        │              │          │
│   • 录入家庭记忆    • 语音对话   │
│   • 配置AI角色     • 一键发起   │
│   • 管理音色       • 无需操作   │
│   • 查看记录         复杂界面   │
└──────────────────────────────────┘
```

### 1.3 当前阶段

项目处于 **第一版内测阶段**，核心功能闭环已完成，正在进行上线前的最后修复与配置收口。
