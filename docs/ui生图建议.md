# 亲情陪伴系统 UI 生图建议

> 本文档面向 UI 概念图生成，描述各页面的界面结构、组件、交互流程和设计要点。
> 基于 ui-analysis.md 中的问题分析，本文档反映所有建议项修复后的目标版本。

## 变更摘要（相对修复前）

| 问题类别 | 修复内容 |
|---------|---------|
| 信息层级 | 首页区分老人入口/家属管理；家庭空间完成度改为可点击跳转的统计卡片；档案页上下区域改为可折叠面板 |
| 老人易用性 | 大按钮增加 emoji 图标；不同通话状态有不同背景色；辅助按钮默认收起；错误提示改为老人友好语言；支持大字模式 |
| 操作安全 | 档案页删除操作增加确认弹窗；危险按钮有红色背景填充 |
| 页面布局 | 档案页上下区域可折叠；音色页移动端导航改为横向标签 |
| 组件规范 | 新增必填字段标记、按钮分组、统计卡片、可折叠面板、区域分隔线等通用样式 |

## 1. 页面清单

| 序号 | 页面名称 | 路由地址 | 页面用途 | 当前功能状态 |

顶部导航栏在所有页面显示（`/login` 除外），包含 6 个导航项，分为两组：

**老人使用组：**
- 老人陪伴 `/elder`

**家属管理组：**
- 首页 `/`
- 家庭空间 `/family`
- 档案记忆 `/records`
- 音色 `/voices`

两组之间用竖线分隔。当前路由高亮激活，底部有 2px 棕色下划线指示。

## 2. 页面结构分析

### 2.1 首页 `/`

**页面区域：**
- 顶部登录状态栏（右侧对齐）
- 产品标题区（居中）
- 简短说明文案
- 主操作按钮区（两个按钮，突出老人入口）
- 功能卡片网格区（老人入口突出显示 + 家属管理卡片组）

**组件：**
- 登录状态文本："已登录：{手机号}"
- 主标题："亲情陪伴系统"
- 说明文案
- 老人入口大卡片（突出显示，占据整行或更大面积，带 "老人入口" 标签）
- 家属管理分组标签
- 家属功能卡片（4 张，含家庭空间、档案记忆、音色、历史）

**按钮：**
- "去登录"（未登录时）
- "开始语音陪伴"（主按钮，深色填充）
- "进入家属管理"（次要按钮，透明边框）
- "退出登录"（已登录时）

**表单：** 无

**数据展示：**
- 已登录用户手机号
- 功能入口的名称和说明

**当前交互流程：**
1. 用户访问首页 → 一眼区分"老人入口"和"家属管理"
2. 已登录 → 点击"开始语音陪伴"进入老人端，或点击家属功能卡片配置
3. 未登录 → 点击"去登录"进入 `/login`

### 2.2 手机号登录 `/login`

**页面区域：**
- 居中卡片式登录面板（最大宽度 520px）
- 表单区（手机号 + 验证码 + 两个按钮）
- 成功/错误提示区

**组件：**
- 标题："手机号登录"
- 提示文案："请输入内测账号和验证码登录。"
- 手机号输入框（类型 tel，placeholder："请输入内测账号"）
- 验证码输入框（placeholder："请输入测试版验证码"）

**按钮：**
- "检查账号"（发送验证码，发送中显示"检查中"）
- "登录"（提交登录，登录中显示"登录中"）

**表单字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| 内测账号 | text (tel) | 手机号 |
| 验证码 | text (numeric) | 测试版验证码 |

**数据展示：**
- 成功提示（绿色）："账号可用，请输入内测验证码登录。" 或 "验证码已发送。"
- 错误提示（红色）：具体错误信息
- 按钮 disabled 状态：发送中、登录中、未填手机号、未填验证码

**当前交互流程：**
1. 输入手机号 → 点击"检查账号"
2. 测试模式下提示验证码为 `000000`
3. 输入验证码 → 点击"登录" → 成功后自动跳转 `/family`
4. 已登录用户自动跳转 `/family`

### 2.3 老人端语音陪伴 `/elder`

**页面区域：**
- 对话对象信息区（居中，顶部）
- 大型圆形通话按钮（居中，最大 260px）
- 通话状态文字（按钮上方）
- 辅助操作按钮区（默认仅显示"更多"按钮，展开后显示完整选项）
- 连续对话提示区
- 错误/状态提示区
- 设置提示区（资料未准备好时显示）
- 最近对话区（默认仅显示 1 条，可展开查看全部）

**组件：**
- 称呼标签："正在和"
- 当前 AI 角色名（大标题，如"女儿 说话"）
- 音色绑定提示
- 通话状态文字（大字，如"可以开始说话啦"）
- 大圆形通话按钮（直径 max 260px，带 emoji 图标 + 文字标签）
- 辅助操作按钮区：
  - "更多 ▾" 按钮（虚线边框，点击展开以下按钮）
  - 连续对话开关
  - 停止播放
  - 重播上一条
- 最近对话卡片（默认 1 条，可展开全部）
- "看更多（还有 N 条）▾" 按钮（超过 1 条时显示）

**通话状态与按钮对应：**

| 状态 | 背景色 | 状态文字 | 按钮图标+文字 | 按钮颜色 |
|------|--------|----------|-------------|---------|
| 空闲 | 暖米色 | 可以开始说话啦 | 🎤 开始说话 | 深棕色 |
| 录音中 | 浅红色 | 正在听你说 | ⏹ 发送 | 红色 |
| 理解/回复中 | 浅灰色 | 正在理解/回复 | ⏳ 正在理解/回复 | 灰色(禁用) |
| 播放中 | 浅绿色 | 正在播放回复 | ⏹ 打断说话 | 绿色 |
| 出错 | 浅红色 | 刚才有点卡住了 | — | — |

**错误提示（老人友好语言）：**
- 浏览器不支持录音："这个手机不能说话聊天，让家人帮你换一个手机试试。"
- 麦克风权限拒绝："还没打开话筒，让家人帮你设置一下。"
- 语音识别为空："没听清，大点声再说一遍吧。"
- 后端失败："刚才没听清楚，你再说一遍就好。"

**表单：** 无传统表单；核心输入为浏览器麦克风录音。

**数据展示：**
- 当前 AI 角色名称 + 音色绑定状态
- 最近对话（默认 1 条，可展开）："您说：……" / "{角色名}：……" + 重播按钮
- 空状态："还没有最近对话。"

**当前交互流程（完整状态机）：**

```
idle（暖米色背景，可以开始说话啦）
  ↓ 点击 🎤 按钮 → 请求麦克风权限
recording（浅红色背景，正在听你说）
  ↓ 点击 ⏹ 发送 → 停止录音 → 进入 understanding
understanding（浅灰色背景，正在理解你说的话）
  ↓ 自动 → ASR 识别
replying（浅灰色背景，正在回复）
  ↓ 自动 → LLM 生成回复 + TTS 合成
playing（浅绿色背景，正在播放回复）
  ↓ 播放结束 → idle（普通模式）或 recording（连续对话模式）
```

**设计要点：**
- 所有元素大号、高对比度，适合老年人视力
- 主按钮足够大（手指可轻松点击）
- 状态变化通过背景色 + emoji 图标 + 文字三重传达
- 辅助按钮默认隐藏，减少老人困惑
- 错误提示用老人能理解的语言
- 支持大字模式（所有文字放大 25%）

### 2.4 家庭空间 `/family`

**页面区域：**
- 页面标题说明区
- 加载/错误/成功提示区
- 已创建家庭空间状态区（家庭信息 + 资料完成度仪表盘 + 下一步入口）
- 未创建家庭空间表单区

**组件：**

已创建家庭空间时：
- 家庭名称（大标题）+ 家庭 ID（灰色小字）
- 成员角色标签（所有者 / 可编辑成员 / 只读成员）
- 用户 ID 标签
- **陪伴资料完成度仪表盘（重点突出）：**
  - 4 张可点击统计卡片（2x2 或 4 列网格）：
    - 老人画像（已完成：绿色边框 + ✓；未完成：橙色边框 + 序号 1）
    - AI 角色（已完成：绿色边框 + ✓；未完成：橙色边框 + 序号 2）
    - 家庭记忆（已完成：绿色边框 + ✓；未完成：橙色边框 + 序号 3）
    - 音色（已完成：绿色边框 + ✓；未完成：橙色边框 + 序号 4）
  - 每张卡片显示大号数字/图标 + 标签
  - 未完成卡片可点击跳转到对应配置页面
  - 全部完成时显示绿色成功文字；未完成时提示点击跳转
- "下一步"区域，4 张入口卡片（2 列网格）

未创建家庭空间时：
- "尚未创建家庭空间"提示
- 说明文字
- 家庭空间名称输入框 + "创建家庭空间"按钮

**按钮：**
- "创建家庭空间"（未创建时）
- "完善档案与记忆"
- "刷新"
- "返回首页"

**表单字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| 家庭空间名称 | text | 创建时必填 |

**数据展示：**
- 家庭名称、ID、成员角色、用户 ID
- 陪伴资料完成度（4 项统计卡片，可点击）
- 加载中："正在加载家庭空间..."

**当前交互流程：**
1. 登录后进入 → 自动加载家庭空间
2. 无家庭空间 → 输入名称 → 创建 → 显示仪表盘
3. 有家庭空间 → 查看完成度仪表盘 → 点击未完成卡片直接跳转配置
4. 全部完成 → 点击"进入老人端"开始使用

### 2.5 档案与记忆 `/records`

**页面区域：**
- 页面标题说明区（含当前家庭名称）
- **上半部分：智能导入区（可折叠面板，默认展开）**
  - 视角切换控件
  - 大文本框 + 操作按钮
  - 解析结果预览区（4 类可编辑数据）
- **区域分隔线**
- **下半部分：已保存云端档案管理区（可折叠面板，默认展开）**
  - 操作按钮行
  - 已保存记录列表（4 类，可展开编辑/删除）

**组件：**

智能导入区（可折叠面板）：
- 面板标题："智能导入家庭资料"（点击折叠/展开）
- 视角分段控件：家人视角 / 老人视角
- 大文本输入框（6-8 行，placeholder 含示例）
- 按钮组：智能解析 + 保存到云端 + 返回家庭空间

解析预览区（4 类可编辑卡片）：
- 老人画像（单条，字段表单）
- AI 扮演角色（单条 + 多条列表）
- "同步创建为家人档案"复选框
- 家人档案（列表）
- 家庭记忆（列表）
- 空状态："解析后会在这里显示可编辑预览。"

已保存云端档案管理区（可折叠面板）：
- 面板标题："已保存的云端档案与记忆"
- 按钮组：保存修改 + 刷新
- 4 类数据列表，每条记录显示名称摘要
- "展开编辑"按钮 + "删除"按钮（红色，删除有确认弹窗）
- 空状态："暂无已保存的云端档案或记忆。"

**按钮：**

| 按钮 | 区域 | 样式 | 作用 |
|------|------|------|------|
| 智能解析 | 导入区 | 主按钮 | LLM 解析文本 |
| 保存到云端 | 导入区 | 次要按钮 | 保存预览数据 |
| 返回家庭空间 | 导入区 | 次要按钮 | 跳转 /family |
| 保存修改 | 管理区 | 主按钮 | 提交已保存记录的编辑 |
| 刷新 | 管理区 | 次要按钮 | 重新加载云端数据 |
| 展开编辑 | 管理区每条 | 次要按钮 | 展开编辑表单 |
| 收起 | 管理区每条 | 次要按钮 | 收起编辑表单 |
| 删除 | 管理区每条 | 危险按钮(红底) | 删除记录（弹出确认框） |

**表单字段（31 个字段，其中 12 个数组字段）：**
- 老人画像（10 字段）：姓名、性别、性格、偏好、习惯、健康备注、说话特点、人生经历、重要记忆、备注
- AI 扮演角色（6 字段）：角色名、与老人关系、对老人称呼、性格、说话风格、陪伴方式
- 家人档案（8 字段）：姓名、性别、关系、性格、偏好、习惯、家庭关系、备注
- 家庭记忆（7 字段）：记忆内容、类型、主语、相关家人、情感标签、话题标签、亲密权重

**数据展示：**
- 当前家庭名称
- 解析预览数据（4 类卡片）
- 已保存云端数据（4 类列表）
- 保存成功提示（含各项保存数量统计）
- 删除成功提示

**当前交互流程：**
1. 家属粘贴资料 → 选择视角 → 点击"智能解析"
2. 检查 4 类预览数据 → 手动编辑 → 点击"保存到云端"
3. 在管理区查看已保存记录 → 展开编辑 → 保存修改
4. 删除操作会弹出确认对话框，显示要删除的记录名称

### 2.6 对话历史 `/history`

**页面区域：**
- 页面标题区（含"家庭复盘"标签和家庭名称）
- 筛选工具栏（3 个下拉 + 刷新按钮）
- 状态提示区
- 对话轮次列表（每条一张卡片）
- 记忆保存编辑面板（内嵌在卡片中）

**组件：**
- 筛选器（3 个下拉框 + 刷新按钮）：
  - AI 角色下拉、老人下拉、时间下拉（全部/今天/最近7天/最近30天）
- 对话卡片（每条）：
  - 元信息行：时间 | 角色名 | 老人名 | 音色名
  - 对话内容区：老人说 + AI 回复
  - 底部信息行：ASR 提供方 | TTS 提供方 | 重播按钮
  - 操作行：生成记忆候选 / 保存为记忆 / 已保存为记忆（绿色徽标）
- 记忆保存编辑面板（展开在卡片下方）：
  - 记忆内容 textarea（4 行）
  - 网格布局字段：类型、主语、相关家人、情绪标签、主题标签
  - 确认保存 + 取消按钮

**按钮：**

| 按钮 | 作用 |
|------|------|
| 刷新 | 重新加载对话历史 |
| 重播 | 播放该轮 AI 回复音频 |
| 生成记忆候选 | 调用 LLM 从对话中提取记忆候选 |
| 保存为记忆 | 打开记忆编辑面板 |
| 确认保存 | 提交记忆保存 |
| 取消 | 关闭记忆编辑面板 |

**表单字段（筛选区 + 记忆保存面板）：**
- 筛选：AI 角色、老人、时间（3 个下拉）
- 记忆保存：记忆内容(textarea)、类型、主语、相关家人、情绪标签、主题标签

**数据展示（每条对话卡片）：**
- 创建时间（MM-DD HH:mm）、角色名、老人名、音色名
- 老人说原文、AI 回复文字
- ASR/TTS 提供方、已保存徽标
- 空状态："还没有符合条件的对话。"

**当前交互流程：**
1. 进入页面 → 自动加载对话历史
2. 使用筛选器缩小范围 → 查看对话内容
3. 点击"重播"听取 AI 回复
4. 点击"生成记忆候选" → LLM 提取 → 审核
5. 点击"保存为记忆" → 填写表单 → 确认保存
6. 已保存的显示绿色徽标

### 2.7 音色管理 `/voices`

**页面布局：** 桌面端左侧导航 + 右侧内容区；移动端顶部横向标签导航

**页面区域：**
- 豆包语音提示横幅（顶部通栏）
- 导航区（3 个标签页）
- 右侧内容区（根据标签页切换）

**左侧导航（桌面端垂直排列；移动端横向标签）：**
- "音色管理"（分组标题）

## 3. 功能模块分析

### 3.1 用户认证
- 手机号 + 验证码登录
- 测试期固定验证码 `000000`
- Token 存储于浏览器 localStorage
- 登录过期后自动跳转登录页

### 3.2 家庭空间
- 云端数据归属单位，所有档案、记忆、音色、对话历史挂载其下
- 单家庭空间模型
- 三种成员角色：owner / editor / viewer
- **资料完成度仪表盘**：4 张可点击统计卡片，点击未完成项直接跳转配置页

### 3.3 老人端语音聊天
- 面向老人的电话式语音交互界面
- **5 种通话状态对应 5 种背景色**（暖米/浅红/浅灰/浅绿/浅红）
- 大圆形按钮为核心操作元素（含 emoji 图标）
- 完整状态机：idle → recording → understanding → replying → playing
- 辅助按钮默认收起（"更多 ▾"展开）
- 最近对话默认 1 条（可展开）
- **老人友好错误提示**（"这个手机不能说话聊天"代替"浏览器不支持录音"）
- 支持连续对话模式
- 自动匹配 AI 角色与音色

### 3.4 老人画像管理
- 10 项属性：姓名、性别、性格、偏好、习惯、健康备注、说话特点、人生经历、重要记忆、备注
- 支持 LLM 智能解析导入 + 手动编辑
- 删除有确认弹窗

### 3.5 AI 角色
- 6 项属性，定义 AI 扮演的家人身份
- 支持多角色，老人端自动匹配
- 可绑定音色

### 3.6 家人档案
- 8 项属性，记录真实家人信息
- 支持从 AI 角色同步创建
- 删除有确认弹窗

### 3.7 家庭记忆库
- 7 项属性，含亲密权重
- 输入来源：手动新增、LLM 智能解析、对话历史提取
- 删除有确认弹窗

### 3.8 对话历史
- 记录每次语音对话的完整信息
- 三维筛选（角色/老人/时间）
- LLM 辅助提取记忆 + 手动编辑保存

### 3.9 音色管理
- 三种类型音色：预置、已导入、已复刻
- 导入已有 Speaker ID 或创建复刻音色
- 音色绑定 AI 角色、试听、重命名、删除
- 桌面端左侧导航，移动端横向标签

### 3.10 云端同步
- REST API 通信，Token 认证
- 所有数据 CRUD 通过 API，无本地持久化

## 4. 用户流程分析

### 4.1 老人用户流程

> 前提：家属已完成所有配置。

```
步骤 1：进入系统
  └→ 家属将 /elder 页面在老人设备上打开（已登录）
  └→ 页面显示暖米色背景

步骤 2：查看对话对象
  └→ 页面显示"正在和 [家人名字] 说话"
  └→ 下方显示"可以开始说话啦"
  └→ 大按钮显示 🎤 开始说话（深棕色）

步骤 3：开始说话
  └→ 点击大按钮 → 背景变为浅红色 → 显示 ⏹ 发送
  └→ 辅助按钮默认隐藏，不干扰老人

步骤 4：等待回复
  └→ 说完自动发送 → 背景变为浅灰色
  └→ 依次显示 ⏳ 正在理解 → ⏳ 正在回复
  └→ 按钮灰色禁用

步骤 5：听到回复
  └→ 背景变为浅绿色 → 显示 ⏹ 打断说话
  └→ 自动播放 AI 回复语音
  └→ 最近对话区显示 1 条文字记录

步骤 6：继续聊天
  └→ 播放完毕后：
    - 普通模式：背景恢复暖米色，回到"可以开始说话啦"
    - 连续对话模式：自动开始新一轮录音
  └→ 可点击"更多 ▾"→"重播上一条"再次听刚才的回复

步骤 7：异常处理
  └→ 没听清 → 提示"没听清，大点声再说一遍吧。"
  └→ 系统出错 → 提示"刚才没听清楚，你再说一遍就好。"
  └→ 资料未就绪 → 提示"请家人先完成设置"
```

**关键设计特点：**
- 单个大按钮，零学习成本
- 状态通过背景色 + emoji + 文字三重传达
- 无需键盘输入，全程语音
- 辅助按钮默认隐藏，减少干扰
- 错误提示用老人能懂的语言

### 4.2 家属用户流程

#### 初次配置流程

```
步骤 1：登录
  └→ 首页 → "去登录" → 输入手机号 → 获取验证码(000000) → 登录
  └→ 自动跳转 /family

步骤 2：创建家庭空间
  └→ /family → 输入家庭名称 → "创建家庭空间"
  └→ 创建成功 → 显示完成度仪表盘

步骤 3：录入档案与记忆
  └→ 点击仪表盘中的"老人画像"卡片（序号 1）→ 跳转 /records
  └→ 展开"智能导入家庭资料"面板
  └→ 粘贴家庭资料 → 选择视角 → "智能解析"
  └→ LLM 自动生成结构化数据 → 检查预览区 → 编辑补充
  └→ "保存到云端"

步骤 4：配置音色
  └→ 点击仪表盘中的"音色"卡片（序号 4）→ 跳转 /voices
  └→ 选择"导入已有音色"或"创建复刻音色"
  └→ 填写表单 → 提交 → 等待训练完成
  └→ 回到"家人音色库"→ 绑定到 AI 角色

步骤 5：交给老人使用
  └→ 回到 /family → 仪表盘全部显示 ✓（绿色）
  └→ 显示"所有资料已就绪，老人可以开始语音聊天了。"
  └→ 点击"进入老人端"→ 确认正常
  └→ 设备交给老人
```

#### 日常维护流程

```
复盘对话：
  └→ /history → 筛选近期对话 → 查看内容 → 重播音频
  └→ 有温度的内容 → "生成记忆候选" → 审核 → 保存

补充记忆：
  └→ /records → 展开"智能导入"面板 → 新增文本 → 解析 → 保存
  └→ 或在管理区直接编辑已有记录

调整音色：
  └→ /voices → 试听 → 不满意则导入新音色 → 重新绑定
```

    - "保存为记忆"按钮（次要样式）
    - 或"已保存为记忆"绿色徽标（已保存状态）
  - 记忆编辑面板（展开时内嵌在卡片下方）：
    - 记忆内容大文本框（4 行）
    - 网格排布的字段：类型、主语、相关家人、情绪标签、主题标签
    - "确认保存"（深色）+ "取消"（透明）

关键操作：筛选对话 → 查看内容 → 重播音频 → 生成记忆候选 → 编辑记忆 → 确认保存

重要状态：
- 加载中："正在加载对话历史..."
- 无数据："还没有符合条件的对话。"
- 已保存为记忆：绿色徽标

目标用户：家属用户

### 音色管理

页面名称：音色管理

核心目标：让家属管理家人声音，导入已有音色或创建复刻音色，并绑定到 AI 角色。

主要内容：

**整体布局：** 桌面端左侧窄导航栏 + 右侧宽内容区；移动端顶部横向标签

**导航区（桌面端垂直，移动端横向）：**
- 分组标题"音色管理"
- "家人音色库"（默认选中高亮）
- "导入已有音色"
- "创建复刻音色"

**右侧内容区：**

*标签页 1 — 家人音色库：*
- 豆包语音提示横幅（顶部通栏，含外链按钮）
- 工具栏：搜索框 + 类型筛选下拉
- 音色卡片网格（2-3 列自适应）：
  每张卡片：
  - 音色名称（可编辑，点击 ✎ 进入编辑模式）
  - 音色类型标签（预置=蓝色 / 已导入=绿色 / 已复刻=橙色）
  - 创建时间
  - 绑定 AI 角色下拉选择框
  - 当前绑定角色显示
  - Speaker ID（可展开/收起）
  - 豆包状态信息
  - 操作按钮行：查询状态 + 试听
  - 试听音频播放器
  - "删除音色"按钮（含确认弹窗）

*标签页 2 — 导入已有音色：*
- 标题 + 说明文字
- 表单：音色类型下拉、音色名称、Speaker ID、授权确认复选框、"添加音色"按钮

*标签页 3 — 创建复刻音色：*
- 标题 + 计费提醒（黄色警告框）
- 表单：音色名称、音频上传、可折叠复刻参数区（音色创建方式、自定义ID、试听文本、语种、降噪开关）、授权确认、"创建复刻音色"按钮

关键操作：搜索/筛选 → 绑定角色 → 试听 → 编辑名称 → 查询状态 → 删除 → 导入已有音色 → 上传音频创建复刻

重要状态：
- 无音色："还没有音色档案"
- 无家庭空间：错误提示 + "去创建家庭空间"按钮
- 无编辑权限（viewer）：操作按钮禁用
- 删除确认弹窗（区分预付费/后付费提示文字）
- 名称编辑模式：内联编辑 + 保存/取消
- 查询中/训练中/添加中：按钮文字变化并禁用
- 创建成功：自动跳回音色库

目标用户：家属用户，偏管理者或配置人员
